# makac.qemu

A [makac](https://github.com/jwdevantier/makac) package that turns makac into a QEMU VM orchestrator: build disk images, boot and resume VMs from snapshots, and hotplug devices over QMP.

- makac: <https://github.com/jwdevantier/makac>
- makac documentation: <https://jwdevantier.github.io/makac/>
- makac.qemu documentation: <https://jwdevantier.github.io/makac.qemu/>
